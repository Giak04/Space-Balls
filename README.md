# Space-Balls

Eliminato l'Ambiente comune nella repo, ognuno deve creare il proprio VENV nella propria macchina (installate pyserial, astropy, scipy e matplotlib)

Dentro la cartella Ambiente ci sono le librerie scaricate e l'attivazione dell'ambiente virtuale.
Per attivare l'ambiente virtuale aprite il terminale nella cartella della repo e digitate 'source ./Ambiente/bin/activate'
Così attivate l'ambiente virutale di Python. Per disattivarlo basta digitare 'deactivate'.
